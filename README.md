基于工作区 m3e-canvas 设计稿实现的 Android 原生安全与系统工具。

- **应用名**：XB工具
- **包名**：`com.xb.tool`

- **作者**：可怜的小兵
- **反馈邮箱**：kelianxiaobingcn@vip.qq.com

## 一、v1.3.7 新增

### 修复无线调试配对「TLS 握手成功之后立刻 Broken pipe」

配对日志以前会停在这样一串：`TLS 握手成功` → `已导出 keying material 64 字节` → `发送 SPAKE2 消息` → `Broken pipe`。三段都"成功"了，却连服务端的一个字节都没收到。

根因是 TLS 上下文没出示客户端证书。设备端的 adbd 配对服务在 TLS 1.3 里会发 `CertificateRequest`，客户端交空证书时，设备端在收到 Finished 后立刻关闭连接；而客户端此刻已经认为握手完成，于是第一次写就吃到 EPIPE。AOSP 的 `SslUtils.getSslContext` 是带 `KeyManager` 的，本应用此前传的是 `null`。

- TLS 上下文现在带本机 ADB 证书（`X509ExtendedKeyManager`，只对 RSA 请求出示）。
- 失败时自动按「带证书 → 不带证书 → libadb-android 官方实现」三种配置依次重试，日志逐条写明每一路卡在哪一步。
- 不会再只给一句"数据交换失败"。

### 关闭极致保活后状态不再残留

- 停止守护时立刻清理 `Heartbeat` 心跳文件。此前只停服务不清心跳，界面会在 65 秒内继续显示"互拉守护运行中"。
- 关闭极致保活时显式 `WatchdogService.stop`，避免 `:watchdog` 进程在自己的 15 秒周期里把 guard 又拉起来。

## 二、v1.3.6 新增

### 无线调试配对改为通知栏内输入

- 系统的「使用配对码配对设备」弹窗一旦离开设置界面就会被销毁，配对端口随之关闭——也就是说**不可能**边看码边切回应用里输入。本版把输入框搬进通知栏：打开系统弹窗后直接下拉通知栏，点「输入配对码并配对」填入 6 位码即可。
- **先存码、后配对**：填码时若 mDNS 还没扫到配对服务，码会先暂存，扫到后立刻自动配对，不会出现「填了码却提示未发现服务」。
- 配对成功后**自动继续启动 ADB 增强服务**，不用再回应用点一次「启动服务」。
- 通知里另加「打开系统配对页」，可直接跳到系统的无线调试设置。
- ADB 增强服务页的启动流程第 4 步也内嵌了配对面板，两条路径任选。

### 其他

- 系统资源检测页补充「哪些字段需要 Root / Shizuku」的说明，并修复占用率百分比与温度不同步的问题。
- 可疑应用扫描排除系统应用并收紧判据，减少对系统组件的误报。

## 三、v1.3.5 新增

### 威胁处置与实时防护

- **四种模式统一处置**：低 / 标准 / 严格 / Shell 模式命中威胁时都会弹出独立告警页（全屏通知 + Activity），可直接**卸载 / 隔离 / 管控 / 删除 / 稍后处理**，不再只记一条日志。
- **Shell 模式包含严格模式的全部能力**：切到 Shell 模式不会丢特权巡检，而是在巡检之上再叠加高危命令监控。
- **严格模式与 Shell 模式强制要求 Shizuku 授权**，未授权时页面直接给出授权入口，不再允许用其它特权通道“降级”进入。
- 通知栏的拦截提醒点击后直接进入处置页，不必再从首页找入口。

### 紧急救机

- 摇一摇阈值大幅上调（标准 / 用力 / 猛摇三档），并改为多峰计数 + 冷却窗口，日常拿起、走动不再误触发。

### ADB 增强服务（无线调试 / 有线 ADB / Root）

- 「无线调试授权」与原来的「特权服务」页合并成一页 **ADB 增强服务**：三种启动方式（无线调试 / 有线 ADB / Root）共用同一个启动器与时间线。
- **关于命名**：早期版本借用过「特权服务」这个词，容易和游龙的 PRIVILEGE CONSOLE 混淆。本版本把界面上的字样全部改成「ADB 增强服务」，代码里的类名 `PrivilegeService` 只是内部实现细节，不再出现在界面上；实现方式也不同 —— 本应用连的是系统自带的 adbd，没有内置任何第三方特权二进制。
- **环境准备**：开发者选项、无线调试开关（显示探测到的 TLS 端口）、配对状态各一行，未满足的直接给按钮跳系统设置。
- **启动过程七步时间线**：准备启动环境 → 检测开发者选项 → 检测所选通道 → 建立/验证 ADB 服务 → 检测系统限制 → 启动特权 → 启动完成；每步有等待 / 进行中 / 成功 / 失败四种状态，失败那步标红并写明原因。
- **状态卡**：运行方式、身份 UID、进程号、启动时间、最近一次错误（可展开常见原因）。
- **运行环境自检**：服务起来后用真实命令逐项测试终端命令、包管理、安全设置写入、AppOps 能不能做，逐项标「可用 / 受限」。
- 支持**启动 / 重启 / 停止**；配对面板并入本页，配对日志可一键复制。
- 需要说明的是：本页启动的是本应用自己那条 ADB 通道，不是把 Shizuku 打包进 APK。普通应用无法在自己的进程里 fork 出常驻 shell 进程，这是 Android 的权限模型决定的。

### 授权应用

- 新增**授权应用**页：列出所有声明了 `moe.shizuku.manager.permission.API_V23` 的应用与本应用自身。
- 每行显示图标、应用名、包名、版本号，可直接打开应用或跳转 Shizuku 管理器。
- 说明写清楚：Shizuku 的授权状态只存在 Shizuku 管理器自己的存储里，普通应用没有权限替别的应用改授权，本页只负责列出来并把你送过去。

### 系统资源检测

- 新增**系统资源检测**页：CPU 型号与核心频率、总体占用、GPU 型号与频率/占用、内存总量/已用/交换分区、系统运行时长。
- 受 Android 权限模型限制，GPU 频率/占用、部分温度与功率必须通过 Root / Shizuku 读取；读不到时显示「不可用」，不猜数字。
- 页面顶部加了**权限说明条**：未授权时显示红底「当前只有普通权限，部分数据读不到」，并给出「ADB 增强服务」「Root / Shizuku」两个跳转按钮；已授权时显示绿底「特权通道已就绪」。
- 说明里写清楚：CPU 型号、核心频率、内存、电池温度都不需要权限；开不开权限的差别只体现在标了「需特权」的字段上。
- 每个受权限影响的字段后面标「需特权」，让“开没开权限”的差别一眼可见。
- 修好了占用率百分比与进度条长度不同步的问题（数值用 500ms 缓动追上去）。
- 工具列表里该入口标注了徽标「部分需 Root」。

### 浏览器

- 起始页改成 **Edge 手机版风格**：深色渐变底、顶部头像与引擎胶囊、中间大 Logo、底部悬浮搜索框、快捷入口一行、底部工具条（后退 / 前进 / 收藏夹 / 菜单）。
- 起始页由 Compose 直接绘制，不加载远程首页，打开速度快且不会被 DNS 广告劫持；搜索词直接进搜索引擎。
- 快捷入口在还没有收藏时给出必应 / 百度 / 谷歌三个默认站点，收藏后自动换成收藏夹里的前三条。
- 地址栏改用自适应输入框，修复文字被裁掉一半的问题；点进地址栏自动全选，输入不会被页面跳转覆盖。
- 桌面版网页自动缩放整页宽度，手机 UA 保持按视口回流，不再出现“页面比屏幕宽、只能左右拖”。
- 返回键行为：网页可后退时先退网页，退到底再回到起始页，最后才退出页面。

### 无线调试

- 连接端口改为多路探测（系统属性 / settings / 监听端口候选逐个尝试），修复配对成功后连接端点端口为 0 导致的失败。
- **配对改为自研客户端**：不再依赖 libadb 的 `PairingConnectionCtx`，自己按 AOSP 配对协议走 TLS 1.3 → `exportKeyingMaterial` → SPAKE2 → AES-128-GCM 交换 PeerInfo，每一段都写进配对日志。
- 失败时不再只有一句“握手失败”，而是给出失败阶段（TLS / 导出密钥 / SPAKE2 / PeerInfo）和具体原因。

## 四、v1.3.2 新增

### 安全与病毒库

- 病毒库支持**公开 SHA-256 哈希列表直链**（例如 MalwareBazaar 导出文本）以及本应用 JSON 格式；MalwareBazaar 导出接口若返回 405，可使用界面内置的公开哈希库镜像（jsDelivr）。
- 在线哈希库会与内置特征库**合并**，更新后不会丢失锁机、广告软件等内置启发式规则。
- 内置特征增加锁机 / 设备管理器劫持 / 广告注入 / 无障碍滥用等文件名与行为启发式规则，版本更新为 `2026.10.25`。
- 新增**紧急救机**：全量扫描所有已安装应用，检查设备管理器、无障碍服务、默认桌面、可疑悬浮窗等锁机风险；支持 Root / Shizuku 强制结束或冻结风险应用。
- 紧急救机新增**总开关**：开启时依次引导授权通知和全屏通知权限；关闭后停止摇一摇监听并清理通知。
- 紧急救机新增**全部应用手动处理列表**：即使样本不在病毒库，也可以搜索、查看应用信息、强制结束或进入系统应用详情；系统应用默认不标为风险，避免误报。
- 新增**隔离区**：实时拦截自动登记样本，扫描结果可手动隔离；支持恢复、移入隔离、删除记录。入口在侧边栏/设置。
- **Root 环境检测**新增设备完整性与残留卡片：Bootloader 状态、构建签名、调试属性、su、Root 管理器、模块残留、SELinux、ADB、系统分区与运行环境。
- 后台守护服务支持**摇一摇触发**（3 次快速摇动，15 秒冷却），同时提供按钮触发、全屏通知和紧急救援页面。
- 紧急救援页面使用 `showWhenLocked` / `turnScreenOn` 覆盖锁屏，并通过全屏通知和独立 Activity 置顶；已移除高风险的悬浮窗权限，避免安全软件把“悬浮窗 + 安装应用”组合识别为自动扣费风险。
- 紧急救机新增**按键触发**（音量键连按 1–10 次，默认 3 次）与摇一摇力度（标准 / 用力 / 猛摇），按键触发需要无障碍服务。
- 设置页新增安全防护区：紧急救机、防广告、隔离区；安全搜索/自动重连/过滤器只在防广告页内设置，避免重复。

### 浏览器与网络防护

- 新增**浏览器**：默认无痕（退出清理 Cookie/缓存/历史）、Bing/Google/百度/DuckDuckGo 搜索引擎切换、收藏夹、广告过滤与桌面版插件、深浅色主题、网页全屏视频；背景沿用应用动态背景设置，顶栏按手机屏幕自适应压缩。
- 新增**网络防护**：本机 DDoS/连接洪泛监测（受系统限制，无法清洗运营商级攻击）、网页风险警告（HTTP、IP 直连、国际化域名、可疑登录页）、DNS 安全过滤联动。
- 病毒库支持**镜像回退**：主源失败自动尝试备用源；更新成功后写入 `virus_db_remote.json` 与 `virus_db_backup.json`，公共服务器不可用时继续使用本地特征。
- 公告页新增**版本更新内容**，按版本列出自 2.5.0 起的更新说明。

- 极致保活与标准保活**双向互斥**；开启极致保活时不再弹窗打断，而是直接进入「极致后台保活」页。页内提供**状态自检**（守护进程 / 互拉守护 / 通知 / 完全后台行为 / 自启动 / 电池优化），ColorOS 系额外提供电池优化设置入口，全部为系统状态实时读取，不再要求手动“已开启”确认。
- 守护进程与互拉守护的心跳改用**跨进程文件时间戳**（`files/hb_guard`、`files/hb_watchdog`）。SharedPreferences 在 `:watchdog` 独立进程里各有一份内存缓存，主进程读不到对方写入的心跳，会误报“心跳超时，可能已被系统清理”；改为文件后两进程都能立即读到最新心跳。
- 「主题设置」改名**自定义个性化**，新增 UI 动画与毛玻璃开关；侧边栏顺序调整为：公告 / 拦截记录 / 白名单 / 自定义个性化 / 更新检测 / 关于。
- 首页在已授权 Root/Shizuku 时显示**内核级保护**入口。

### 实时防护模式与特权通道

- 防护强度改为四档**模式**：低模式 / 标准模式 / 严格模式 / Shell 模式；**严格模式必须基于 Shizuku 权限**，由守护进程用特权通道周期巡检全部已安装应用（含系统应用）与受保护目录，页面显示上次巡检时间、巡检应用数与命中条数。
- 新增 **Shell 模式**：通过特权通道周期性读取系统进程表，把 shell 命令归因到发起它的应用，识别静默卸载、清除数据、篡改系统设置、提权、下载即执行等行为。实时防护页新增 **Shizuku 授权卡片**，可直接申请权限或跳转 Root / Shizuku 页面；无线调试配对成功后会自动通知守护模块接管特权通道，与杀毒、实时检测联动。
- 新增**高危命令弹窗拦截**：命中高危命令时弹出独立告警页，显示应用名、包名、风险等级（中高风险 / 高风险 / 极高风险）、行为描述与完整命令，并提供「强力卸载」「仅本次忽略」。受 Android 权限模型限制，普通应用无法在内核层阻止命令执行，因此处理方式是立即告警并引导卸载。
- 新增**可疑应用弹窗**：仅检测到可疑应用（无障碍 + 悬浮窗组合、设备管理器滥用等）时同样弹窗提示处理，不必等到命中具体命令。
- 无线调试页新增**配对日志**面板：配对与连接的关键步骤实时写入本地日志，失败时可直接看到失败在哪一步，支持一键清空与复制。

### 病毒库与更新

- 支持**自动检查更新**（1/15/60/360 分钟可选）与**自动更新病毒库**开关。
- 公告页新增**版本更新内容**（2.5.0 起）。
- 新增**用户协议 / 法律条款 / 作者声明**启动弹窗与关于页入口；开源许可清单补全。

### 首页

- 顶部标题「XB工具」，三条杠打开侧边栏（公告、更新检测、白名单、关于、拦截记录、主题设置）。
- 安全总览：Root / Shizuku 状态、实时防护、病毒库版本、最近扫描、累计拦截。
- **普通杀毒**：已安装应用与常用下载目录，无需权限。
- **强力杀毒**：系统分区、受保护目录与系统应用，需要 Root 或 Shizuku；未授权先弹出双滑块提醒。
- **实时病毒检测**：前台服务监控 Download、DCIM、Pictures、Movies、Documents、Music 等目录与新安装应用，命中特征后通知并写入拦截记录。
- 病毒库版本点击联网检测；实时日志终端；拦截记录；所有文件访问授权提示。

### 设置

- 后台保活机制：需要通知权限；未授权不允许开启。
- 极致后台保活：标准保活 + 双进程互拉；额外要求电池优化白名单；标准与极致只需开启一个，极致已包含标准。
- Shizuku / Root 授权：双滑块提醒，可关闭提醒。
- 通知管理：系统通知设置、扫描/拦截/更新/权限提醒开关、测试通知；右上角状态按钮可直接跳转授权。
- 主题设置：7 种主题色、浅色/深色/跟随系统、字体大小、字体、图片/视频背景、模糊、透明度。
- 缓存清理：显示占用并一键清理。

### 环境

- JDK 17 或 21
- Android SDK Platform 35、Build-Tools 34/35
- Gradle 8.9（项目自带 wrapper，分发地址使用腾讯镜像）

```powershell
$env:JAVA_HOME="C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot"
.\gradlew.bat assembleDebug
# 或
.\gradlew.bat assembleRelease
```

`local.properties` 指向当前机器的 SDK：

```properties
sdk.dir=D\:\\DEEPSE~1\\ANDROI~1\\sdk
```

APK 输出：

```
app/build/outputs/apk/debug/app-debug.apk
app/build/outputs/apk/release/app-release.apk
```

> Release 变体使用项目内 `keystore/xb-release.jks` 正式签名（RSA 2048），不再使用 Android Debug 证书；签名配置读取 `keystore.properties`。

## 七、更新清单格式

默认更新源（可在「更新检测」中修改）：

```
https://raw.githubusercontent.com/kelianxiaobingcn/XB-Tool/main/update.json
```

示例：

```json
{
  "app": {
    "versionCode": 132,
    "versionName": "1.3.2",
    "url": "https://example.com/XB-Tool-2.6.0.apk",
    "sha256": "可选",
    "notes": "更新说明"
  },
  "virusDb": {
    "version": "2025.01.01",
    "url": "https://example.com/virus_db.json",
    "sha256": "可选",
    "notes": "病毒库说明"
  },
  "announcements": [
    {
      "id": "a1",
      "title": "公告标题",
      "date": "2026-10-25",
      "tag": "公告",
      "important": true,
      "content": "公告内容"
    }
  ]
}
```

病毒库 JSON 与 `app/src/main/assets/virus_db.json` 格式一致；下载后保存在应用私有目录，通过版本号与 SHA-256 校验后生效。

**火绒 / 360**：两家暂未提供公开的特征库 API，因此不会直接抓取它们的私有病毒库。可自行维护 JSON 特征库并填入更新源。

## 九、当前限制

1. 蓝奏云新版节点会下发 JS 反爬/CDN 校验；应用内提供校验浏览器，校验完成后可接管下载。123 云盘可解析分享文件列表，但免登录下载链接目前会被官方拦截，应用会打开分享页交由浏览器/登录处理。接口可能随官方策略变化。
2. 百度 / 阿里 / 夸克 / UC / 移动云盘等需要登录或专用接口，暂不自动解析。
3. 病毒库在线更新支持自建 JSON 或公开 SHA-256 哈希列表；公开哈希库多为通用恶意样本，不能保证覆盖所有 Android 锁机变种，未知样本请用紧急救机的全部应用列表手动处理。MalwareBazaar 等公开源可能限速、需要网络可达，且哈希列表只匹配文件 SHA-256。
4. 极致互拉守护受 Android 12+ 后台启动与厂商省电策略限制，不能保证 100% 拉起；状态页可查看心跳与运行状态。
5. 视频背景依赖 Media3；背景模糊仅 Android 12（API 31）及以上生效。
6. MP3 编码使用 LAME JNI，FLAC 使用纯 Java 编码，均在本机完成；超大音频文件转换时间较长。
7. Root / Shizuku 能力取决于设备；模拟器与未授权设备上会给出失败提示。
   无线调试通道（免 Root）要求系统开启「无线调试」，且每次开机后需保持该开关；配对码只在系统「使用配对码配对设备」弹窗存活期间有效，所以必须从通知栏输入配对码。Android 15 起平台 Conscrypt 移除了 `exportKeyingMaterial`，应用内置了自定义 Conscrypt（Apache 2.0）完成 TLS 1.3 配对。
8. 紧急救机的摇一摇依赖后台守护服务；锁屏置顶需要系统全屏通知权限，强制冻结风险应用需要 Root / Shizuku。
9. 防广告只处理 IPv4 DNS 查询（UDP 53），不代理 HTTP/HTTPS、不处理 DoH/DoT；某些应用自带 DNS 或使用私有解析时可能绕过过滤。
10. 应用包含 VPN、全屏通知、所有文件访问、应用列表和自更新安装等高权限能力；部分手机管家会给出“高风险/扣费风险”泛化提示。应用不包含短信、支付或计费 SDK，也没有任何电话/短信相关权限（`READ_PHONE_STATE` 等被依赖库合并进来的权限已在清单里用 `tools:node="remove"` 显式移除），相关能力均需用户主动授权。

## 十、隐私与许可

- 扫描结果、公告缓存、白名单、拦截记录、主题配置均保存在本机。
- 只有在你点击检测/更新时，才会访问你配置的更新源；云盘解析会请求对应分享页。
- 使用的开源组件：AndroidX / Jetpack Compose、Kotlin Coroutines、OkHttp、Shizuku API（Apache 2.0）、libadb-android（Apache 2.0）、Conscrypt（Apache 2.0）、spake2（Apache 2.0）、Bouncy Castle（MIT）、LAME（LGPL）、java-flac-encoder（LGPL）、AndroidX Media3（Apache 2.0）。

**请勿将本工具用于未经授权的设备或非法用途。**
